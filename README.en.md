# Role Card · dsh-role-card

> Paste a character card into the DeepSeek Harness sidebar and you are in character on save. Switching cards or leaving the role is one click.

A fully local DSH sidebar plugin. Cards, chat history and novel chapters live in `~/.dsh/dsh-role-card/` on your own machine; every line the character speaks is generated by the model route your local Harness already has configured.

```
┌─ Sidebar ──────────┐   ┌─ Panel ──────────────────────────────┐
│ Role cards         │   │ Shen Yan · in character   size  age   │
│ ─────────────────  │   │ ───────────────────────────────────  │
│ ▸ Shen Yan  12.4k  │   │ She set the cup down; the base hit    │
│   Lin Wan    8.1k  │   │ the desk…                            │
│ ▸ Novel (3/12)     │   │                                      │
│                    │   │ ───────────────────────────────────  │
│ + New card         │   │ Say something… (Enter to send)  [→]  │
│ Import from URL…   │   └──────────────────────────────────────┘
└────────────────────┘
```

> **Repository**: <https://github.com/yugege123/dsh-role-card>. Fork it and point `origin` at your own account if you want to maintain a variant.

## Features

- **Always in the sidebar** — registered on both `sidebar.panellist` and `main`; the role only speaks inside that panel, never in your other sessions.
- **Paste and play** — body limit 400 KB, up to 200 cards.
- **URL import** — SillyTavern PNG cards (`chara` / `ccv3`), RSC payloads, `__NEXT_DATA__`, JSON-LD, OpenGraph.
- **AI expand** — turn a one-line premise into a full, playable card; the prompt can be overridden by an external file.
- **Novel mode** — import the first 40 chapters instantly, then continue in 40-chapter batches (or let a background job finish the whole book), check for new chapters on the site, inject only the current chapter (≤ 9000 chars) each turn.
- **Five per-card dials** — content mode (adult / normal), tone (5 levels: none / hint / soft / explicit / hard), pace (slow / steady / direct), style (RP / novel / chat / script / diary), ages (adult / as-written).
- **Direct model calls** — since v1.3 turns go straight through `ctx.llm.stream`: no Agent, no session files, no global prompt section.
- **Phone access** — password-protected LAN reverse proxy with a QR code for same-WiFi devices.
- **Local only** — no telemetry, no cloud, no external requests except the fetches you trigger yourself.

## Install

1. Open your profile directory, e.g. `~/.dsh/profiles/desktop/`.
2. Add the dependency to its `package.json`:

   ```json
   "dsh-role-card": "github:yugege123/dsh-role-card"
   ```

3. Add `"dsh-role-card"` to `dsh.profile.bundles` in the same file.
4. `pnpm install` inside the profile directory.
5. Restart the Harness desktop app — a "角色卡" panel appears in the sidebar.

For local development use `"dsh-role-card": "link:/absolute/path/to/dsh-role-card"` instead; edit code, restart the host (client-only changes just need a page refresh).

## Quick start

1. Open the "角色卡" panel in the sidebar.
2. Either paste a card URL into the import box and hit **导入**, or click **新建角色卡**, paste your card, and **保存**.
3. Click **开场** to let the character speak first, or **进入角色** to start yourself.
4. Type in the box at the bottom: `Enter` sends, `Shift+Enter` is a newline.
5. Tune mode / tone / pace / style / ages from the toolbar (takes effect on the next turn); **退出角色** leaves the role.

The UI is currently Chinese-only (the panel strings are hard-coded); the plugin metadata in `locale/` is localized for zh / en / ja.

## Modes and dials

| Dial | Values | Notes |
|---|---|---|
| Content mode | `adult` (default), `normal` | `normal` is a hard gate: no sexual content at all, and the tone dial is forced down to *none* (only a manual *hint* survives) |
| Tone | `none`, `hint`, `soft` (default), `explicit`, `hard` | how far a scene goes: 300-700 / 400-800 / 400-900 / 700-1200 / 700-1200 chars |
| Pace | `slow`, `steady`, `direct` (default) | only injected in adult mode with a tone above *none* |
| Style | `rp`, `novel` (default), `chat`, `script`, `diary` | single POV / prose / instant messages / screenplay / diary |
| Ages | `adult` (default), `original` | `adult` rewrites under-18 markers in the prompt only; saved text is never touched |

Sampling follows the dials: `temperature` 1.1 for *hard*, 1.02 for *explicit*, 0.9 otherwise; `maxTokens` 2200 for chat, 1600 for RP, 4000 otherwise. Exact wording of every contract: [`docs/PROMPT-CONTRACT.md`](docs/PROMPT-CONTRACT.md).

## Card format

Plain markdown, no required fields. A structure that plays well:

```markdown
# Name
> Source: link or "user setting"

## Profile            identity, age, appearance, current situation
## Personality & voice  temperament, sore spots, 2-3 verbatim sample lines
## Relationships      her ties to me and to others; what led here
## Current scene      where this happens, what she is doing right now
## Hooks              three different ways the scene can escalate
## Continuity rules   what must hold, what may change, what to avoid
```

See [`examples/card-sample.md`](examples/card-sample.md) and [`docs/CARD-FORMAT.md`](docs/CARD-FORMAT.md).

## Data

```
~/.dsh/dsh-role-card/
├── state.json          # all cards (bodies included), version: 1
├── lan.json            # phone-access toggle state
├── expand-prompt.md    # optional external expand prompt
├── chat/<cardId>.json  # per-card history, last 300 messages
└── novels/<cardId>.json# chapters + current pointer
```

Writes are serialized per card (`tmp` + `rename`) to avoid `EPERM` on Windows. "清空对话" renames the file to `.deleted-<ts>` rather than deleting it. `novels/<cardId>.json` keeps both the site's chapter count (`plan.total`) and what has been imported so far, so the panel can show `n/bookTotal` and offer *continue importing*.

## Configuration

| Env var | Default | Purpose |
|---|---|---|
| `DSH_HOME` | `~/.dsh` | data root; the plugin uses `<DSH_HOME>/dsh-role-card/` |
| `DSH_ROLE_CARD_NOVEL_DIR` | `<DSH_HOME>/dsh-role-card/novels` | chapter files |
| `DSH_ROLE_CARD_EXPAND_PROMPT` | `<DSH_HOME>/dsh-role-card/expand-prompt.md` | expand prompt override |
| `DSH_ROLE_CARD_LAN_STATE` | `~/.dsh/dsh-role-card/lan.json` | phone-access password + port persistence |

## API

Every route lives under `/api/dsh-role-card` and requires `x-dsh-role-card: <per-boot token>` (or `ui`). The token is injected as `window.__DSH_ROLE_CARD__.token`, so same-origin plus a custom header is what keeps cross-site calls out. Full endpoint table: [`docs/API.md`](docs/API.md).

```bash
curl -s -H "x-dsh-role-card: ui" http://127.0.0.1:<webPort>/api/dsh-role-card/state
```

## Privacy

No network calls of its own, no telemetry, all data local, token-guarded API, password-guarded phone bridge. Fetching only happens when you click import / expand / novel-import. Report vulnerabilities per [`SECURITY.md`](SECURITY.md).

## Known limits

- Requires the DSH host services (`ctx.llm`, `slots`, prefix API routes); a major host bump may need alignment.
- Novel import only handles server-rendered table-of-contents pages; JS-rendered or login-walled sites fail with a readable error.
- "Continue importing" is fixed at 40 chapters per click; a full-book import runs as a background job (100 chapters per batch).
- Phone access is plain HTTP with a single shared password; trusted LAN only.
- One conversation line per card — no branches or multiple saves (duplicate the card instead).
