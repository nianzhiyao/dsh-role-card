# 截图放这里

`README.md` 顶部有一个注释掉的截图位：

```markdown
<!-- ![面板截图](docs/images/panel.png) -->
```

想让它显示出来：

1. 截一张面板图（建议 1440×900 以上，侧栏 + 主面板同时入镜；窄屏可以再补一张 `panel-mobile.png`）；
2. 存成 `docs/images/panel.png`；
3. 删掉 `README.md` 第 7-8 行的注释符号。

截图注意：**先新建一张空卡或用示例卡**（`examples/card-sample.md`），别把自己的对话内容截进去——这张图会随仓库公开。

预览用的临时卡可以这样造：面板 →「新建角色卡」→ 粘 `examples/card-sample.md` 的内容 → 保存 →「进入角色」→ 发一句话让它有回复 → 截图。

已有素材也可以直接放这里，命名建议：

| 文件 | 用途 |
|---|---|
| `panel.png` | 主截图（README 顶部） |
| `panel-mobile.png` | 手机端（`docs/LAN.md` 可引用） |
| `edit.png` | 编辑页 / 导入区（`docs/CARD-FORMAT.md` 可引用） |
